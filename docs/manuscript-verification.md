# Q1 원고 기능 검증 기록

검증일: 2026-09-23. 대상: Paper2Agent Studio의 기존 결과 기반 원고 작성 기능.

- 새 테스트 17개: 원고 API → 실제 DOCX/ZIP 생성, 원본/차수 보존, 보완 자료/저널 규정 수정, 잘못된 파일·크기 제한·손상 JSON, 실행 결과 스냅샷, 취소/재시작, 숫자·인용문·자료 역할 검사, Word/PDF/CSV 추출, 발췌 표시, 스캔 경계/심볼릭 링크, 읽기 전용 SQLite/철회 제외/저널 연도·분야, 원문 경로 제한.

## 실제 서비스와 모델 검증

명시적으로 표시한 합성 소프트웨어 시험 자료를 사용했다. 임상 연구 자료나 사용자의 논문을 생성한 것이 아니다. 직접 계산한 40개 합성 레이블의 상수 분류기 결과(30개 정답, 정확도 0.75)를 초안과 CSV로 제공했다.

실제 Claude CLI 분석 → 로컬 DB에서 12건의 문헌 검색 → 원고 작성 → 별도 검토 → 수정 → 재검토 → 내보내기를 약 7분에 완료했다. Word/Markdown/검토 보고서/수정 내역/BibTeX/근거 JSON/ZIP의 HTTP 다운로드 7종을 확인했다. 저자 정보·최신 투고 규정 등 누락 자료가 있어 `needs_evidence`로 종료했으며 완성/게재 승인을 허위 표시하지 않았다.

문헌 원문 연결은 실제 `MedicalAI_Papers`의 TXT 경로가 코퍼스 상대 경로라는 점을 반영해 별도로 확인했다. 예시 검색 상위 4건 중 원문 TXT가 있는 2건은 원문 발췌, 나머지는 초록으로 반환됐다. 검색은 원본 DB를 수정하지 않는다.

## 화면과 Word 출력

- Chromium: 1440px 데스크톱, 390px 모바일에서 가로 넘침과 JavaScript 오류 없음.
- 파일 선택, 옵션 입력 중 포커스 유지, 탭 전환 시 선택 유지, 6단계/모바일 3열 진행 표시, 실제 DOCX 다운로드, 원고 미리보기, 업로드 오류 표시 확인.
- 서버 재시작 후 완료된 원고와 다운로드 경로 복원 확인.
- 실제 원고를 최종 DOCX 내보내기로 다시 생성하고 LibreOffice로 5쪽 렌더링. 모든 페이지 이미지에서 제목·본문·참고문헌·결과 표·페이지 번호의 배치와 잘림 여부 확인.
- 검증 원고와 화면/렌더링 자료는 `/tmp/p2a-manuscript-live-qa`에 보관. 시험 원고 2개는 앱의 사용자 작업 목록에서 제거하고 같은 디렉터리에 보존했다.

## 범위

이 검증은 소프트웨어 동작과 제한된 시험 입력에 대한 확인이다. 논문의 임상 타당성, 원본 데이터의 진위, 저널 게재 가능성, 모든 보고 지침 항목의 준수 여부를 증명하지 않는다. 현재 원고 내보내기는 일반적인 Word 원고 형식이며 출판사별 공식 Word 템플릿을 자동 적용하는 기능은 아니다.
